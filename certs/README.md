# FURS test certificate directory

Place your FURS test certificate here as `furs_test.p12`.

## How to obtain a FURS test certificate

1. Visit **FURS test portal**: https://blagajne-test.fu.gov.si/
2. Register your company (DAVČNA ŠTEVILKA required)
3. Request test digital certificate — it's free
4. Download the `.p12` (PKCS#12) file
5. Place it in this directory as `furs_test.p12`

## Files

- `furs_test.p12` — your test certificate (NOT included in repo, .gitignore'd)
- `README.md` — this file
